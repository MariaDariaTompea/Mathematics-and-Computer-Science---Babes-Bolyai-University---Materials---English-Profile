===================================================================================
                                THE RAM LANDSCAPE
===================================================================================

  THE STACK ZONE (Auto-Cleaned)                THE HEAP ZONE (You Must free())
  -----------------------------                -------------------------------

1. SIMPLE INTEGER
   [ int age = 21; ]
   ┌───────────────────────┐
   │       age: 21         │ ──(No Arrows)──> [ Lives completely on the Stack ]
   └───────────────────────┘


2. SINGLE-DIMENSIONAL ARRAY (STRING)
   [ char* s = "Hi!"; ]
   ┌───────────────────────┐                  ┌───┬───┬───┬────┐
   │  s: [0x55a01040]     │ ────────────────> │ H │ i │ ! │ \0 │  (4 sequential bytes)
   └───────────────────────┘                  └───┴───┴───┴────┘
                                              ▲
                                              └─ Memory Address: 0x55a01040


3. DYNAMIC MULTI-DIMENSIONAL MATRIX (7 Rows x 3 Columns)
   [ int** m; ]
   ┌───────────────────────┐
   │  m: [0x55a09900]     │ ────────┐
   └───────────────────────┘         │
                                     ▼
                              [ HEAP BLOCK A: ROW ANCHORS ]
                              ┌───────────────────────────┐
                              │  m[0]: [0x55a02210]       │ ────┐
                              ├───────────────────────────┤     │
                              │  m[1]: [0x55a02250]       │ ────┼────┐
                              ├───────────────────────────┤     │    │
                              │  m[2]: [0x55a02290]       │     │    │
                              ├───────────────────────────┤     │    │
                              │  ...                      │     │    │
                              ├───────────────────────────┤     │    │
                              │  m[6]: [0x55a02390]       │     │    │
                              └───────────────────────────┘     │    │
                                                                │    │
         ┌──────────────────────────────────────────────────────┘    │
         │  ┌────────────────────────────────────────────────────────┘
         ▼  ▼
      [ HEAP BLOCKS B0 - B6: ACTUAL ROW DATA NUMBERS ]
      ┌───┬───┬───┐
  B0: │ 1 │ 2 │ 3 │   <-- Memory Address: 0x55a02210 (Target of m[0])
      └───┴───┴───┘
      ┌───┬───┬───┐
  B1: │ 4 │ 5 │ 6 │   <-- Memory Address: 0x55a02250 (Target of m[1])
      └───┴───┴───┘
      ...
      ┌───┬───┬───┐
  B6: │19 │20 │21 │   <-- Memory Address: 0x55a02390 (Target of m[6])
      └───┴───┴───┘
